STEP 2
Install Wrangler & log in to Cloudflare

The site publishes to Cloudflare Pages (free). You'll need a Cloudflare account and Node.js.

  1. Sign up (free): dash.cloudflare.com/sign-up
  2. Install Node.js if you don't have it: nodejs.org — then reopen your terminal.
Terminal
npm install -g wrangler
wrangler login

wrangler login opens a browser to authorize — click Allow.

✓
STEP 3
Create the Pages project & point .env at it

Create the project once:

Terminal
wrangler pages project create github-trending --production-branch main

Then open Github-Trending\.env and set this line (it's already stubbed in the file):

.env
CLOUDFLARE_PAGES_PROJECT=github-trending

STEP 4
Do a first deploy — confirm the site goes live

Build the data file and push the site up:

Terminal (in the repo)
cd "A:\Claude\Project Skills\Github-Trending"
uv run python -m github_trending.assemble

Wrangler prints your live URL — something like https://github-trending.pages.dev. Open it: you should see the trending board with real summaries. 🎉

Want a custom domain? Add it later in the Cloudflare Pages dashboard → your project → Custom domains.

STEP 6
Run the first full sweep

This crawls every ≥500★ repo and appends today's snapshot after your loaded history. It takes ~2–3 hours (GitHub's rate limits, not a bug) and publishes when done.

Terminal (in the repo)
cd "A:\Claude\Project Skills\Github-Trending"
uv run python -m github_trending.orchestrate

Watch progress in logs\run-<date>.log. If anything fails, you'll get a Discord alert and the live site keeps yesterday's data. After this, the scheduled task keeps it fresh every day — you're done.

Tuning later: the trending thresholds live in github_trending/trending.py (WINDOWS) — adjust once you see a few days of real results.
