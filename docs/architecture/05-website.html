Showing it

The website is deliberately the simplest possible thing: a single static page that reads one small data file. There's no server and no database behind it — the heavy machine work already happened on your PC.

The handoff file: latest.json

Between the pipeline and the website sits one file — a contract both sides agree on. The pipeline writes it; the website reads it. It's small (about 140 KB) and holds everything the page needs:

three windows
day / week / month, each with its top 50 repos
per repo
name, stars, the gain, the Gemini summary, language, topics
a sparkline
the repo's last ~30 days of star counts, to draw its trajectory
a version
so the file's shape can evolve without breaking the site
pipeline
assemble.py
→
latest.json
the contract, ~140 KB
→
the website
reads & renders it

The page itself

It's plain HTML, CSS, and a little JavaScript — no framework, no build step. When it loads, it fetches latest.json and draws the "momentum board": a ranked list per window, each repo showing its velocity, its summary, its language, and a little trajectory sparkline. Real GitHub avatars, light and dark themes, and it works on a phone.

Why so simple? Because the data is already computed. A static file loads instantly, costs nothing to host, can't be hacked (there's no server logic), and means your 2.6 GB of raw data never leaves your machine. Only the tiny result travels.

Where it's hosted

The page and its latest.json are uploaded to Cloudflare Pages — a free static host with a global network, so it loads fast anywhere. Each day's file is also saved as a dated copy in an archive/ folder, which leaves the door open for history charts later without re-computing anything.
